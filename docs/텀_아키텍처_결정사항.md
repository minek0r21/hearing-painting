## ★ 프로젝트 목표 (2026-11-25 확정, 모든 판단의 기준)

> **들리는 그림은 그림 속 장면을 "들을 수 있는 공간"으로 바꾸는 AR 감상 앱이다.**
> **메인 기능**: 그림을 비추면 장면의 소리들이 그림 속 물체의 위치와 깊이에 맞춰 3D 공간에 놓이고, 어디서 무슨 소리가 나는지 눈으로 보인다.
> **엔진**: 이 소리 세계는 AI 파이프라인(물체 찾기 → 깊이 추정 → 소리 설계 → 소리 생성)이 만들어, 작품마다 사람이 소리를 만들지 않고도 새 그림으로 넓혀 갈 수 있다.

- 프레임: **C. AI + AR 결합(지능형 AR)** — 메인은 "깊이 기반 공간 음향 배치와 시각화", AI는 그것을 만드는 엔진
- 대상: **그림을 감상하는 모든 사람** (시각장애인 감상·미술 교육은 확장)
- 작업 분류
  - 메인을 직접 키우는 일: 소리 배치 품질, 추적 안정화, 집중 모드
  - 메인을 받치는 엔진: AI 파이프라인 자동화 (VLM, SAM 3, 깊이, 소리 생성)
  - 메인을 보여주는 확장: 그림 사이 이동, 충돌로 섞기 (수업 기술 응용)
- 보류 중인 grilling 질문: Q19 구조 C, Q20 소스 유형 3분류, Q21 scene.json 확장, Q24 VLM 측정 조정, Q27 평가셋 그림 구성, Q28 Gemini 비교 규칙 → 목표 확정 후 다시 묻기
- 추가 보류 질문: Q29 추적 안정화를 12/03 개발 1순위로 올릴지, Q30 AR 신기능 1개 선택(제안: 소리를 그림 밖으로 꺼내기)

### 4-5. 사라짐·교체 규칙 (B1 제안)
- **규칙 1. "보여야 하는데 안 보이면 사라진 것"**
  - 조건: 그림 네 모서리 모두 화면 안 + 거리 ≥ 너비 0.5배 + 정면 60° 이내 + 그런데도 추적 안 됨 → 1.5초 지속
  - 처리: 0.5초 페이드아웃(소리 포함)
  - 화면 밖이거나 너무 가까우면 유지 → "다가가도 남아 있음" 장점 보존
- **규칙 2. "같은 자리면 최근에 나타난 그림이 이김"**
  - 두 세계 중심이 너비 절반 이내로 겹치면, 가장 최근에 새로 추적이 시작된 그림만 남김
- 숨긴 세계는 지우지 않음. 다시 안정적으로 인식되면 새 위치로 재고정 후 페이드인
- 최후 수단: 리셋 버튼(B7)에 **AR 세션 초기화** 포함 (ARCore 기록을 비우는 유일한 방법, 커뮤니티 해법)

### 4-5-3. 집중 모드 (11/26 그릴링 F1~F4)
- F1 버튼 없이 항상 자동 (Inspector `Focus Mode`로 끄기) / F2 가운데가 아닌 그림은 음량 25%(-12dB), 링 밝기도 음량에 따라 약 48%로 흐려짐(기존 `SetMix` 연동) / F3 전환: 새 그림이 5° 이상 더 가운데인 상태가 0.3초 이어질 때만, 35° 안에 그림이 없으면 모두 원래 크기, 끌기 중엔 멈춤 / F4 데모에 "모니터를 옮겨 비추면 소리가 넘어감" 장면
- 우선순위(기존 유지): 꺼내기(다른 그림 숨김) > 솔로 > 다가가기 강조 > 집중 모드
- 확실한 것(코드 확인): 음량 변화 약 0.4초(초당 2), 25% = -12dB, 링 투명도 연동. **추정(실기기 조정 필요)**: 35°·5°·0.3초 값, "설명 없이 이해됨"은 의견
- 부작용: `active`는 위쪽 제목·두 손가락 깊이 조절 대상도 정하므로 이 둘도 0.3초 늦게 바뀜
- 영상 소리: 11/25 데모 영상 오디오 평균 -39.7dB·최대 -8.0dB(무음 아님). 앱 소리인지 마이크인지는 미확인 → 녹화 설정을 "미디어 소리(마이크 끔)"로

### 4-5-4. 그림 꺼내기 층 틈 메우기 (11/26, 보고서 `reports/그림 꺼내기 층 틈 메우기.md` 추천안 전체)
- **파이프라인** `03_제작/local_ai/layers.py`: 깊이 → 면적이 같은 4층(블러·분위수·중간값 필터) → 층 k마다 앞 층(0..k-1)을 그림 폭 4%만큼 넓힌 구멍을 big-lama(TorchScript, 설치 없이 직접 로드, Apache-2.0)로 채움 → **자기 층 영역은 원본 픽셀을 다시 붙임** → RGBA PNG(1024px). 알파 = 자기 영역 + 앞 층 뒤로 18%(끝 40% 구간 서서히 사라짐), 가장자리는 바깥으로만 0.6% 부드럽게. 가장 먼 층은 불투명 배경판. 층 지도 `layers.bytes`(200칸, depth.bytes와 같은 구조)
- 묶음: `out_<key>/layers/` → Unity `Resources/HearingPainting/<key>/layers/` (rainy_day는 `HearingPainting/layers/`). `pipeline.py` 3단계에서 자동, 기존 그림은 `python layers.py <그림> out_<key> --to-unity <폴더>`. 시간: LaMa 3회 약 8초(+깊이)
- **Unity**: `DepthWindow`가 PNG와 층 지도가 있으면 그걸로 층을 만들고(소리원 층도 이 지도 기준), 경사면(필러)은 펼칠 때 끔. 없으면 예전 방식. 에디터 `LayerTextureImporter`가 가져오기 설정 자동(Clamp·밉맵·알파 투명)
- **원근 맞춤** `PopLayerScale`: 펼친 층 크기 = popScale × (eye − 나온 거리)/eye (최소 0.3). 기준 시점(1.5w)에서 모든 층이 원래 그림처럼 맞물리고 옆으로 볼 때만 벌어짐. 소리원 위치도 같은 식. 기본값으로 가장 가까운 층은 2.5배 → 1.25배
- Inspector 비교 토글: `useBakedLayers`(미리 만든 층), `popPerspective`(원근 맞춤)
- **보고서와 다르게 한 것**: 재질을 알파 혼합으로 바꾸지 않고 기존 알파 잘라내기 유지. 이유: 혼합은 깊이를 안 써서 소리 구·선과 앞뒤가 틀어짐, 같은 셰이더의 투명 변형을 쓰는 재질이 장면에 없어 빌드에서 빠질 위험(추정). 윤곽이 1024px 픽셀 단위라 품질 손해는 작음(추정)
- 투영 시뮬레이션으로 고친 것: ① 구멍 1.2% → 앞 물체 잔상(rainy_day 두 사람) → 4% ② 넓힌 구멍 때문에 정면에서 사람 주변 번짐·가로등 지워짐 → 자기 영역 원본 붙임 ③ 안쪽 부드럽게 → 알파 잘라내기에서 윤곽선 → 바깥쪽으로
- **남은 한계**: 배경판은 구멍이 80% 넘어 가운데가 뭉개짐(hunters 나무 줄기 뒤 회색 얼룩, 옆으로 크게 움직일 때만 보임). 띠만 다시 채우기는 앞 물체 잔상이 되살아나 기각. 원근 맞춤 기준 거리(1.5w)와 실제 보는 거리가 다르면 정면에서도 조금 어긋남 → **실기기 확인 필요**
